# REST API and lifecycle reference

The canonical REST reference moved to the Ideation Hub platform plugin. Do not copy it back into this plugin.

From this file, when the platform plugin sits next to the requirements plugin in this repository (or the plugins are installed as sibling directories):

`../../../../ideation-hub-platform/references/rest-api.md`

That file is also `references/rest-api.md` inside the `ideation-hub-platform` plugin. If this relative path is missing, open the installed platform plugin and read that file. The requirements plugin requires the platform plugin. Cursor's marketplace format has no dependency field; the dependency is documented in this plugin's manifest, README, and `SKILL.md`.
