# Changelog

## 1.1.0 (2026-11-27)

- Principle (`PRN-NNN`) is a record type. It is the broadest record in the specificity order.
- `respects` links a requirement to a Principle. The inverse is shown as Respected by.
- MCP catalog: `ih_list_applicable_principles`, `ih_propose_principle_adoption`, `ih_list_principle_conflicts`, and `ih_propose_principle_conflict`.
- Tenant-wide adoption is done by a human tenant admin in the web app, not through MCP.

## 1.0.0 (2026-11-22)

- First release of the platform plugin. Schema, REST API, and MCP catalog live here. The developer and requirements plugins point here.
