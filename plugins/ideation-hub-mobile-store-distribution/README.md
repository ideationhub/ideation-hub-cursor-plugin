# Ideation Hub Mobile Store Distribution plugin

Download size, startup, offline use, on-device scanning, consumable purchases, and store privacy disclosures for a mobile app on the Apple App Store and Google Play.

The agent instructions are an Agent Skill so hosts can load them: `skills/ideation-hub-mobile-store-distribution/SKILL.md` (name `ideation-hub-mobile-store-distribution`, version 0.1.0 beta).

This plugin is standalone. It does not require the Ideation Hub platform plugin, and it is not part of `ideation-hub-developer`. It does not ship an MCP server. The root `ideation-hub` compatibility bundle does not load this skill. Install this plugin in addition to that bundle, or in addition to the platform, developer, and requirements plugins.

A generated single file for hosts with no plugin and no skill loader is `docs/instructions/ideation-hub-mobile-store-distribution.md`.
