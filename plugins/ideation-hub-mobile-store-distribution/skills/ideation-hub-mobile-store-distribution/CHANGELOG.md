# Changelog

## 0.1.0 (2026-11-26) — beta

- First release. Standalone skill `ideation-hub-mobile-store-distribution`, not part of `ideation-hub-developer`.
- Store download limits for the App Store and Google Play, with the 200 MB figure labeled as a warning or a legacy threshold rather than the current hard cap.
- How to set and measure binary-size and startup budgets. Worked-example budgets: iOS thinned download ≤ 30 MB, Android compressed download ≤ 25 MB, cold start under 2 seconds.
- Offline-first behavior, on-device price-tag scanning, consumable trip credits, and camera, location, and privacy disclosures.
- Official pages were re-read on 26 November 2026. Linked from `references/`.
